# Project UI development Skill

[Japanese](README.ja.md)

`sync` copies `SKILL.md` and `references/` into the app's `.agents/skills/project-ui/`, then generates adjacent `project-context.md` from the source YAML. Consumer documentation is copied into `references/docs/`.

Read the Skill and the relevant context/API before UI changes. Placement alone does not establish an AI tool's automatic selection or loading. After configuration or package updates, review the dry run and synchronize again. Use `SKILL.md` and the English operational references. Human-facing guides are available in [English](../../docs/ui-library-consumer-guide.en.md) and [Japanese](../../docs/ui-library-consumer-guide.ja.md).

For screen design and component selection, the Skill links to an on-demand English reference. Localized fixes use relevant runtime and verification contracts instead.
