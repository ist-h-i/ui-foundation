# Component-specific verification

Read this only for the controls used by the app. Confirm exact inputs and outputs in the [component contracts](docs/ui-components.en.md) and [runtime guide](ui-library-runtime.md).

## Layout, actions and feedback

- Test Grid breakpoints against the actual container and ResponsiveVisibility against the viewport. Sticky positioning uses the closest scroll region. With Panel, Accordion, Splitter, and Card, preserve projected inputs when collapsing content and move only focus that was inside the hidden region. Check narrow widths, enlarged text, and overlapping hover, focus, disabled, busy, and error states. A contrast calculation alone cannot establish readability.
- Keep Toggle's accessible label stable and expose selection with `aria-pressed`. Verify SegmentedControl radio, icon, label, and legend wrapping at enlarged text, including long unbroken labels. Check Toolbar focus when an action moves into or out of overflow. CopyButton announces success after the writer confirms it. Test rejection, retry, expiry, and disposal while waiting.
- Use NotificationHost for concurrency, FIFO, and deduplication. A notification with actions inside a modal needs an internal host and `uiNotificationScope`. Connect notice actions, more results, and cancellation to the app's operations. Test stale, partially available, and unknown feedback separately. Check Spinner delay, indeterminate progress, Skeleton reduced motion, and the exact region made inert. Tour targets an actual HTMLElement, may outlive a lost target, and must restore its owned focus.
- ReadMore must measure overflow again when text, width, or max lines change. Alerts and controls whose own button disappears need an in-component focus destination. Leave outside focus untouched.

## Text, numeric and form controls

- Put Typography on native headings and emphasis, retaining their document hierarchy. Pair semantic foregrounds with their intended surfaces. Test local scrolling for no-wrap text and app-specified tab order.
- Check Badge overflow with the full count available, and Tag selection and removal as separate native actions. Test Avatar image failure, source retry, grapheme fallback, clipping at each size, and AvatarGroup disclosure. Use native description lists and preserve zero, false, empty, and unknown values. A zero comparison denominator has no percentage change. Use native meter for known ranges, and verify RTL number/unit separation and unequal range order.
- Connect HelpText through `aria-describedby` and configure ShortcutHint descriptions. Test CodeBlock source preservation after formatting failure, original JSON tokens and duplicate keys, source line numbers with wrap/blank lines, and copy behavior before/after completion or disposal. Watermark is decorative, does not intercept input, and needs no authorization or content-protection role.
- Test label layout inheritance, native and Angular disabled behavior, Textarea growth after resize or reappearance, and async SearchInput suggestions against query and request ID even when the text repeats. Typed combobox options are for display. Test Escape, Tab, outside click, and a popup inside a modal.
- For MaskedInput, preserve raw values, incomplete drafts, and IME through edits and blur according to its options. OTP preserves leading zeroes and rejects excess digits. TagInput validation applies to the collection, including duplicate/limit checks. Check focus after tag removal. Use native submit/reset with guarded FormActions and connect app confirmations to actual I/O.
- For Slider, RangeSlider and Knob, check positive step, invalid models, non-crossing bounds, keyboard and pointer cancellation. Rating uses native radio choices and explicit clear. ColorPicker preserves incomplete input across focus; verify alpha zero, validation with alpha disabled, formatting on blur, and the same editor across profile changes.
- InlineEdit and FilterBuilder acknowledge only matching pending requests. Keep failed drafts and use `invalidatePending` before a same-turn app model change that invalidates an outstanding response. Match restored filter model to native control display, especially zero, false, missing values, fixed operators, and nested conditions. Test Wizard's explicit branches, disabled or removed steps, old pending request rejection, return path, and preserved projected DOM. The app decides when to approve deferred transitions.

## Popups, navigation and commands

- Dialog and its Drawer/BottomSheet variants preserve projected inputs across size and position changes. Test their native disabled controls while busy, cumulative move/resize keys, and focus recovery after failed save and successful close. Attach popup anchors with an actual HTMLElement. Use `read: ElementRef` for a directive query when its native element is required.
- Tooltip only describes its anchor. Verify delay, Escape, timer cleanup, and owned descriptions. Expose HoverCard's supplemental info to keyboard users. Popover lifecycle covers scope loss, hidden anchors, async close handling, and removal. In ConfirmPopover, verify that a requested action blocks closure until busy takes over or the next render releases the guard. Escape respects child key handling and composition. A pending topmost overlay still consumes Escape, so it cannot dismiss a parent. Test actual document-root direction, profile, and inert changes.
- Use native links for navigation and native disclosure for hierarchy. Preserve the app's URL/current/disabled state. Browser geometry alone is insufficient to identify a usable descendant of a closed disclosure. For Tabs check manual activation, RTL, keyboard order, visibility, and the last-panel focus fallback. Let the app decide whether a tab can close and keep stable panel IDs.
- For AnchorNavigation verify placement and current section with the actual scroll root, sticky offsets, and scroll padding. Restore owned style properties and selector focus without erasing later app changes. Menubar must handle root roving, nested loops, disabled states, typeahead, and leaving by Tab. MegaMenu exposes group headings and links through ordinary Tab order.
- CommandPalette needs a live modal, searchable groups, its actual shortcut and request acknowledgement. Keep its native search input through list refresh. On narrow or enlarged layouts, check that the search and active command remain inside the rendered clipping regions and can be hit. Verify no results, long errors with local scrolling, keyboard retry, disabled repeat submission, and cleanup after destruction. Wait for DOM or ARIA changes before testing keys after a locale/profile switch.

## Collections and specialist views

- For List/Masonry/DataView, use stable keys and typed item templates. Verify DOM order, absolute and page indexes, page/state repair, and preserved inputs across list/grid mode. Verify that virtual lists recycle rows and measure correctly under changed text size, profile, width, and RTL. Save drafts by item key outside the row. Check the end of the list, prefetch, horizontal overflow, and cleanup. A fixed row height or an app-projected template requires its own fit test.
- Listbox and SelectionList options must remain keyboard-selectable without nested actions. Preserve disabled or search-hidden selected values. Verify accessible virtual groups and rendered active options in the accessibility tree. Native radio groups spanning virtual rows need the full membership, effective hidden/disabled flags and canonical value via `radioGroups`. Keep dynamic configuration as a signal. Compare keyboard entry to native groups on the same browser, and leave selection and arrow wrapping to the native controls.
- Sortable/Transfer use the same permission decision for keyboard and pointer; reject operations based on outdated snapshots. Verify Escape cancellation and the next Escape reaching the parent. TransferList/PickList retain hidden/disabled selections and unknown/duplicate model values, check limits for the whole batch, and allow users to reduce invalid values. Projected editors and outside focus must survive internal controls disappearing.
- InfiniteScroll and Timeline acknowledge the same host and request ID. Test rapid inputs, stale/reset/destroyed loads, end of results, real intersection, and retry. Increment content version only after app data or cursor advances. ActivityLog preserves native disclosure state and uses timestamps with explicit offset and time zone. Distinguish missing from invalid dates.
- Verify Calendar's focused date and real control visibility after month/year changes at narrow widths, enlarged text, and RTL. Kanban should retain an actionable focused card and actual move target after reorder or column transfer. For FlowEditor compare SVG endpoints with actual node positions and sizes after text growth, zoom, and layout. Confirm edge label association and focus restoration after deletion. Keep fixed FilterBuilder operators fully visible.
- Check native submission/focus around condition saves, spreadsheet calculation and media playback or retry. For async completion, retain source data, retry after failure, and keep any control the user moved focus to. Test deployed worker/assets, readiness and error paths with actual responses.
