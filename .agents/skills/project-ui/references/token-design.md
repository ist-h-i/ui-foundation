# トークン設計と比較

プリミティブには具体値、セマンティックには用途を置く。例としてblue-700とgreen-700を用意し、color.actionから参照する。プロファイルを変えると同じ役割を別の値へ結び替えられる。focus、選択、警告、重大操作は主操作と意味が違うため、見た目の都合で一つにまとめない。

案内を読みながら進める利用と、同じ一覧を日常的に比較する利用では、文字・余白だけでなく情報の優先順位も異なりうる。属性だけで違いを決めず、同じ課題を両方の案で行えるか確認する。compact化のために判断材料、操作領域、エラー、復旧を削らない。

生成後は意味トークンの値と実computed styleの対応を確認する。外側のprofileと異なる内側のprofile、hover/focus、処理中、エラー、欠損、文字拡大を含める。色ペアの計算は限られた色の組合せの証拠であり、理解・業務の正しさ・総合アクセシビリティの証明ではない。
