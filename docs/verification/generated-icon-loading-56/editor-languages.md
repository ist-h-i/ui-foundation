# CodeEditor の言語拡張の取得量

Angular CLI 22.3.0 の開発サーバーで、開始画面から `loadComponent` の遅延ルートを開き、既定の `<ui-code-editor />` に `plain-text-probe` と入力した。最適化なし、ソースマップあり、CLI キャッシュ無効。開始画面の通信完了後から入力が反映されて通信が落ち着くまでに Chromium が取得した JS 応答の本体を合計した。修正前後で Angular の設定・依存・ブラウザー・アプリ・生成物のパスをそろえ、毎回新しい開発サーバーと Chromium を起動した。

| JS 応答（非圧縮バイト） | 修正前 | 修正後 |
| --- | ---: | ---: |
| 開始画面の合計 | 5,297,602 | 5,297,602 |
| プレーンテキストの遅延ルートの合計 | 5,278,212 | 4,227,069 |
| 同ルートの最大応答 | 1,456,633 | 1,456,633 |

プレーンテキストの初回取得は 1,051,143 B 減った。修正前は JavaScript、JSON、Markdown と、Markdown の依存である HTML・CSS の CodeMirror 言語パッケージが実際に取得された。修正後はこの5パッケージが取得された JS のソースマップに含まれず、同じテキストを入力できた。エディター本体と各言語が必要とする依存は、その機能を使うときに読み込まれる。

リポジトリの `npx playwright test tests/ui/editor-language-loading.spec.ts` は生成したエディターを Chromium で操作する。初期のプレーンテキスト、言語パッケージを取得する順序、取得失敗時の編集、切り替え後の選択・元に戻す操作を検証する。[回帰試験](../../../tests/ui/editor-language-loading.spec.ts)
