# 初期設計

この文書は [要件原文](project-brief.ja.md) を実装へつなぐ設計の出発点です。まだスキーマやAPIを提供する実装はありません。提案をコードと検証に固定する際は、変更点と未確定項目を明示します。

## 目的と範囲

一度決めたUI方針を再説明せず次の画面を開発でき、共通挙動の逸脱を検出し、必要な例外を理由付きで扱える状態を目指します。共通化するのは判断基準、部品の使い方、状態と操作の意味です。一覧と編集のレイアウトを一致させる必要はありません。

単一リポジトリ・単一npmパッケージ、Angular／TypeScriptを初版の範囲とします。YAMLを全画面仕様のDSLにしません。LLM API、モデル選択、APIキー、課金、サーバー、DB、ASK連携・Router・Ledger、管理ダッシュボード、UX総合点は範囲外です。GitHub Actionsは完了条件にせず、ローカルのnpmコマンドで検証できるようにします。

## 1. 設定の最小項目

利用アプリの `ui.config.yaml` を唯一の設定の正本とします。`context` は自然言語による判断材料です。CLIが文章から見た目を推測して確定してはいけません。`target`、`design`、`components`、`checks`、`exceptions` は検証した機械設定として解釈します。

| 区分 | 初期案 | 責任 |
| --- | --- | --- |
| `schema_version` | 1 | スキーマの世代を識別する。未対応版は明確に拒否する。 |
| `context` | product、users、goals、usage、constraints | 人・AIが必要な文脈を読む。自由記述を自動的な視覚ルールへ変換しない。 |
| `target` | framework、source、generated_ui | 初版のframeworkはangular。入出力と所有範囲を確定する。 |
| `design` | preset、density、locale | 承認済みプリセットと設定を解決する。 |
| `components` | 五つの部品群 | 検証済みテンプレートの採用範囲。 |
| `checks` | include、規則ごとのseverity | 解析範囲とerror／warningを明示する。 |
| `exceptions` | 初期例は空配列 | 逸脱の対象と理由を明示する。形式は実装前に確定する。 |

一般原則はプリセットへ置きます。機能ごとの状態遷移、データの依存関係、業務ルールは機能の仕様・コード・試験に置き、YAMLへ二重管理しません。

未確定事項は、例外の具体的な構造、severityの全選択肢、利用アプリに必要なAngular／Node／TypeScriptの対応版、設定エラーの診断形式です。依存パッケージ導入前に対象版と互換性を確認します。

## 2. 生成物の所有範囲

```text
ui.config.yaml
  → 構造と必須値の検証
  → プリセットと設定の解決（共通の設定オブジェクト）
      ├─ UI部品・スタイル
      ├─ プロジェクト用Skill・必要時に読む参照ファイル
      └─ 静的検査設定
```

自然言語からAIが提案する工程と、承認済み設定を通常のプログラムが生成・検査する工程を分けます。三つの出力は同じ解決結果を参照します。例えば処理中の操作抑止を、部品、Skillの状態接続指示、検査・操作試験の観点へ同時に反映します。

| 利用アプリ内の配置 | 所有者と扱い |
| --- | --- |
| `ui.config.yaml` | 人が管理する設定の正本。 |
| `.ui/generated/policy.json` | 生成物。二つ目の正本にしない。YAMLの解決結果と照合する。 |
| `.ui/generated/tokens.css` | 生成する文字・余白・色・状態・モーションの共通設定。 |
| `.ui/generated/manifest.json` | ツール版、設定、前回生成内容を照合するための記録。形式は今後確定する。 |
| `.agents/skills/project-ui/` | CLIが管理するプロジェクト用Skill。詳細を参照ファイルへ分ける。 |
| `src/app/shared/ui/generated/` | CLI管理の部品。直接編集で修正しない。 |
| `src/app/shared/ui/custom/`、機能、`tests/ui/` | 人・AIが開発する個別拡張、業務実装、操作試験。同期で再生成しない。 |
| `AGENTS.md`、`package.json` | 合意した管理対象部分だけ更新し、既存内容・既存スクリプトを保全する。 |

予定するCLIは `init`、`sync`、`check` です。インストールと初期化を分離し、postinstallにソース変更を持たせません。

同期は `--dry-run` で対象と差分を表示し、同じ設定・ツール版では不要な差分を出しません。前回の内容と現在の内容を照合し、手編集、未所有ファイルとの衝突、管理部分の衝突では黙って上書きせず診断します。機能コードを生成対象にしません。設定・ツール版・生成物をGitで追跡します。パスの境界、symlink、途中失敗時の処理、削除を含む差分の扱いは実装前に定義し試験します。

## 3. 共通部品と利用アプリの責任

| 部品群 | 基盤が提供する内容 | 利用アプリが接続する内容 |
| --- | --- | --- |
| PageFrame | 主情報、判断材料、本文、操作の配置基準。不要なサブタイトルを挿入しない。 | 画面の目的、必要情報、比較・判断に必要な量。 |
| ActionControl | 通常、focus、押下、処理中、無効、重大操作の意味。ボタンとリンクの区別。 | 実処理状態、業務上の可否、重複更新の防止。 |
| FormField | ラベル、必須・任意、補助、入力エラー、選択状態の関連付け。 | 値、検証、入力保持、業務上の妥当性。 |
| AsyncRegion | 領域単位の取得中、正常、空、更新失敗、部分欠損、局所再試行の表示。 | データの信頼性、依存関係、安全に継続できる範囲。 |
| ActionFeedback | 結果、復旧操作、実際に利用可能なUndo、不可逆操作の影響説明。 | 成功条件、実データの復元、取消の可否と対象、対象・影響範囲。 |

標準HTML要素や既存の基礎部品を優先します。focus、選択、無効、処理中を一つのactiveフラグへまとめません。色・アイコン・hover・ドラッグだけに依存せず、意味のあるコントロール、見えるfocus、必要な状態通知、クリック／タップの代替を設けます。モーションは因果関係や連続性のために使い、動きを減らす設定でも意味を保ちます。

Undo表示を実データの復元保証と扱いません。通信中断を変更取消と表示しません。応答が届かなければ、結果不明として安全な確認経路へ接続します。未確認の失敗扱いによる再実行は二重更新を招きます。

部分障害では正常部分と入力を保ち、欠損の影響を表示します。判断に必要な情報が不足する操作は、利用アプリの判断で止めます。未解決の障害は影響領域に残し、一瞬のトーストだけで終わらせません。AsyncRegionのMVPは明示的なデータ取得状態を対象とし、描画例外の隔離を保証しません。

「追加より削除」「1画面1目的」「主操作は1つ」を無条件の禁止にしません。必要な比較情報や理解を保ちながら不要な負担を減らします。

## 4. 機械検査で断定できる範囲

| 層 | 実施する確認 | 結果の意味 |
| --- | --- | --- |
| 静的 | 設定と生成物の一致、値と部品の逸脱、プロパティ、用語、危険な構造。 | 機械検査の対象範囲で違反が見つかったか。UX全体の合格ではない。 |
| 実操作 | 処理中の再操作、入力修正、局所失敗、結果不明、実Undo、キーボード、画面幅。 | 対象アプリと対象シナリオで観測した振る舞い。 |
| AI・人 | 目的適合性、情報優先度、文言、必要な比較情報、理解と実利用。 | 文脈に基づく判断。少数事例から一般化しない。 |

TypeScriptはAST、Angularはテンプレート解析、CSSは構文解析で扱います。angular-eslintやStylelintの拡張など既存の解析機構を検討し、検証済み規則へ設定を渡します。正規表現だけで全てを判定せず、毎回AIに検査コードを生成させません。具体的な依存とAPIは初期化段階では未選定です。

禁止対象を適用領域と承認済み経路に限定します。トークン定義内の値、計算用の値、対象外コードまで一律に禁止しません。解析できない動的指定は判定不能として報告します。日本語検査はUI文言の役割に合わせ、短いラベルへ本文の文体や句点を強制しません。

部品利用はimport数でなく実際の静的利用箇所を数えます。ループは静的に一箇所で、表示実数・頻度とは異なります。標準／承認済み、標準外、理由付き例外、判定不能を分け、分母を明示します。判定不能や例外を隠して100%と表示せず、数をUX品質や不要な部品追加の目標にしません。

Skill導入も、UI依頼で選ばれることと非UI依頼で過剰に適用されないことを確認します。配置しただけで適用済みと断定しません。
